# 🍽️ EliteDine – Restaurant Booking Platform - [Live link!](https://elite-dine.vercel.app/)

A full-stack restaurant booking platform built with **MongoDB, Express, React, Node.js, and TypeScript (MERN + TS)** featuring role-based access for **Users**, **Restaurant Owners**, and **Admins**.

The platform allows users to discover restaurants using advanced filters, book tables, owners to manage their restaurants and bookings, and admins to approve restaurants before they become publicly visible.

---

## 🚀 Features

### 👤 User

- Browse approved restaurants
- Search restaurants by name
- Filter restaurants by:
  - Price range
  - Cuisine
  - Availability
  - Location
  - Rating
- View restaurant details
- Book tables
- View booking history

### 🏪 Restaurant Owner

- Register and list restaurants
- Upload restaurant images
- Manage restaurant details
- Accept or reject booking requests
- View restaurant booking activity

### 🛡️ Admin

- Approve or reject newly listed restaurants
- Monitor platform statistics
- View registered restaurants
- Manage platform approvals
